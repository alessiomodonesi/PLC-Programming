# Siemens Simatic PLC - Industrial Automation Labs

Repository contenente il codice sorgente, gli esercizi e le esercitazioni pratiche per la programmazione dei **PLC Siemens Simatic** sviluppati con **TIA Portal**, nell'ambito del corso di Automazione Industriale (Università degli Studi di Padova).

## 🏢 Panoramica

Il corso fornisce le basi pratiche e teoriche per la programmazione e configurazione dei PLC della serie Siemens Simatic (S7-300 / S7-1200 / S7-1500). L'obiettivo è sviluppare logiche di controllo industriale strutturate e modulari gestendo segnali digitali, registri di memoria, blocchi dati e manipolazione del flusso di esecuzione (RLO).
